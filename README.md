## CS 240 - Computer Organization
This CS 240 repository contains a variety of assignments from the CS 240 class, including a ASCII-to-Decimal Converter, Bitmap-to-Text-File Converter, Text-File-To-Bitmap-Converter, and a Base Number Converter.

## Projects

### ASCII-to-Decimal Converter
This ASCII to Decimal Converter allows the user to input a string (for example, their name), and returns a comma-delimited integer list of the ASCII Decimal values of each character in the input string.

### Number-Base Converter
The Number-Base Converter converts numbers supporting binary(base 2), octal(base 8), decimal(base 10), and hexadecimal(base 16). The program validates the user's input and outputs the equivalent value in the selected output base. It also tests boundary cases such as zero, the largest supported unsigned value, and negative values represented using two's complement.

### Bitmap-to-Text-File Converter
The Bitmap-to-Text-File Converter reads the pixels from a bitmap image and converts them into text-based color codes. These codes are written to a text file so that the image's pixel data can be viewed, stored, or processed as text.

### Text-File-to-Bitmap Converter
The Text-File-to-Bitmap Converter reads color codes from a text file and uses them to create a bitmap image. Each code represents a specific RGB color and determines the color of the corresponding pixel in the generated image.
